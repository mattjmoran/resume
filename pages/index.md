# Matthew J. Moran's Resume

A LaTeX-based resume template with resources and best practices for creating an
effective resume.

## Getting Started

### Local

For local development with version control:

1. Clone the [repository][GitHub Repository]
1. Run `./build.sh resume.tex` (requires Docker)
1. Outputs `resume.pdf` to the current directory

### Web

Use an online LaTeX editor to get started quickly:

1. Download [`resume.tex`][Resume LaTeX] from the repository
1. Import it into [Overleaf](https://www.overleaf.com/),
   [Crixet](https://crixet.com/), or any other online LaTeX editor
1. Edit and compile directly in your browser

## Features

- Clean, professional layout optimized for ATS compatibility
- Dockerized build process for consistent results across environments
- Modular LaTeX structure for easy customization
- Version control friendly (no binary files in source)

## Motivation

Word processors like Google Docs and Microsoft Word make it difficult to
maintain consistent formatting and don't integrate well with version control.
Since resumes require frequent updates, these limitations become problematic.

LaTeX and Git provide a better solution for managing document versions.
This text-based approach makes it easier to track changes and create tailored
versions for different opportunities.
